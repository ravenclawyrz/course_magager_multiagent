# 课程作业管理助手

基于 Python 标准库(tkinter或pyQT)的课程作业管理 GUI 程序

## 要求

用python生成一个课程作业管理的GUI程序，实现以下功能：

1. 添加课程，存储课程的名称和上课时间（必有）、地点和授课教师等（可选）

   支持“第x节到第x节”的形式：8:00-8:45第1节，8:55-9:40第2节，10:00-10:45第3节，10:55-11:40第4节，12:00-12:45第5节，12:55-14:00第6节，14:00-14:45第7节，14:55-15:40第8节，16:00-16:45第9节，16:55-17:40第10节，18:00-18:45第11节，18:55-19:40第12节，19:45-20:20第13节

   课程时间存在冲突时，提醒用户，但允许相应操作

2. 管理课程，可以对课程信息实现修改或删除课程

3. 针对某个课程添加作业，存储作业要求和提交截止时间

4. 展示课表

5. 根据当前时间提醒上课日程和作业，如果距离作业提交截止不足24小时需要给出提醒

6. （重要）必须正常显示和输入中文

## 功能

| 功能     | 说明                                                         |
| -------- | ------------------------------------------------------------ |
| 添加课程 | 课程名称、上课时间(星期 + 起止时间)为必填项;上课地点、授课教师为可选 |
| 管理课程 | 对已有课程进行修改或删除(删除课程时其作业一并删除, 并有确认提示) |
| 作业管理 | 为指定课程添加作业(作业要求 + 提交截止时间), 支持修改、删除、按课程筛选 |
| 课表展示 | 按星期展示一周课表, 当天一列高亮显示                         |
| 智能提醒 | 上课前 30 分钟及上课期间弹窗提醒;作业距截止不足 24 小时(或已逾期)弹窗提醒 |

### 提醒规则

- 程序启动时和运行期间每 **30 秒**自动检查一次;
- 上课前 **30 分钟**及上课期间 → 弹窗提醒上课;
- 作业距提交截止**不足 24 小时**或已逾期 → 弹窗提醒, 并在作业列表和"今日提醒"页用橙色/红色标出;
- 同一天同一事项只弹窗提醒一次, 避免重复打扰;
- "今日提醒"页集中展示今日课程(还有多久开始/进行中/已结束)和所有作业的截止状态。
